# SCOTUS Briefs — A Citizen's Guide to Supreme Court Cases

This repository archives primary Supreme Court PDFs and publishes plain-language, source-cited case guides at [scotusbriefs.us](https://scotusbriefs.us/).

The project is being rebuilt from scratch. See `openspec/changes/launch-citizens-scotus-guide/` for the implementation plan.

Python archive and contract commands are documented in [`docs/python-pipeline.md`](docs/python-pipeline.md); authoritative discovery sources are documented in [`docs/official-sources.md`](docs/official-sources.md).
